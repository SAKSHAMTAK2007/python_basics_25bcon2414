# Factorial Calculator

A simple Python program that calculates the factorial of a given number using an iterative approach with a `for` loop.

## 📌 Project Description

This project demonstrates how to calculate the factorial of a number in Python. The program initializes a factorial value and iteratively multiplies it by each integer from `1` through the given number.

For example, the factorial of 5 is:

**5! = 5 × 4 × 3 × 2 × 1 = 120**

## ✨ Features

* Calculates the factorial of a number.
* Uses a simple iterative approach.
* Beginner-friendly Python implementation.
* Easy to understand and modify.

## ▶️ Usage

Run the program using:

```bash
python factorial.py
```

The current program calculates the factorial of `5`.

To calculate the factorial of another number, modify the value of `n` in `factorial.py`:

```python
n = 5
```
